## 功能概述

### 1. 任务标签系统
为任务添加多标签支持，区别于单一分类，允许任务属于多个标签，便于灵活筛选和组织。

**主要功能**：
- 创建/编辑/删除标签
- 为任务添加/移除多个标签
- 按标签筛选任务
- 标签颜色自定义

### 2. 任务模板
保存常用任务结构为模板，快速创建重复性任务，提高效率。

**主要功能**：
- 创建/编辑/删除模板
- 从模板快速创建任务
- 将现有任务保存为模板
- 模板包含标题、描述、分类、等级、子任务

### 3. 智能提醒
为任务设置提醒，在截止时间前通过浏览器通知提醒用户。

**主要功能**：
- 预设提醒时间（5/15/30分钟、1/2小时、1天前）
- 浏览器通知推送
- 提醒管理（创建/删除）
- 通知权限管理

### 4. 搜索与筛选增强
提供全文搜索和高级筛选功能，帮助用户快速找到任务。

**主要功能**：
- 全文搜索任务标题和描述
- 高级筛选（分类、等级、状态、日期范围）
- 筛选预设保存/加载
- 快捷键支持（Cmd/Ctrl + K）

## 建议实现顺序

按照价值和依赖关系，建议按以下顺序实现：

1. **搜索与筛选增强**（约 2 天）
   - 无数据库依赖
   - 立即提升用户体验
   - 为其他功能提供筛选基础

2. **智能提醒**（约 3 天）
   - 数据模型已存在
   - 独立功能，无依赖
   - 提升任务完成率

3. **任务模板**（约 2.5 天）
   - 需要新增数据库模型
   - 独立功能，无依赖
   - 提升重复任务创建效率

4. **任务标签系统**（约 3 天）
   - 需要新增数据库模型
   - 与搜索筛选功能协同
   - 提供更灵活的任务组织方式

## 技术栈说明

所有功能方案均基于项目现有技术栈：

- **框架**: Next.js 16 (App Router) + TypeScript
- **数据库**: Cloudflare D1 (SQLite) + Prisma ORM
- **状态管理**: TanStack Query + Zustand
- **UI**: Tailwind CSS 4 + shadcn/ui
- **认证**: NextAuth.js v5
- **国际化**: next-intl

## 实现注意事项

1. **Edge Runtime**: 所有 API 端点需要使用 `export const runtime = 'edge'`
2. **D1 数据库**: 使用 `getD1Client()` 获取数据库客户端
3. **认证**: 使用 `auth()` 获取当前用户会话
4. **国际化**: 所有文案需要添加到 `messages/zh.json` 和 `messages/en.json`
5. **工作日志**: 每次提交前需要更新 `WORKLOG.md`
