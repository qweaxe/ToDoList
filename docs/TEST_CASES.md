## 修复记录

### 2026-06-01 修复：任务编辑时属性不生效

**问题描述**：编辑已有任务时，修改分类或优先级后保存，属性不会更新。

**根本原因**：
1. `TaskForm.tsx` 中 `useEffect` 的依赖项包含 `initialData` 对象引用，导致每次父组件渲染时都会重新执行 `reset()`，覆盖用户的修改
2. `setValue` 调用缺少 `shouldValidate` 和 `shouldDirty` 参数

**修复方案**：
1. 使用 `useRef` 跟踪已初始化的任务 ID，只有当任务 ID 改变时才重置表单
2. 在 `setValue` 调用中添加 `{ shouldValidate: true, shouldDirty: true }` 参数
3. 改进 `onSubmit` 中的数据处理逻辑，正确处理空字符串和 null 值

**修改文件**：`src/components/task/TaskForm.tsx`
