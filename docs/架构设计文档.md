# ToDo List 应用架构设计文档

## 1. 项目概述

### 1.1 项目愿景
构建一个极简、直观且具有高度交互性的待办事项管理应用，支持按天管理任务，并提供多维度视图（日、周、月、季、年）进行宏观规划和数据统计。

### 1.2 核心特性
- 多类型任务支持：基础任务、跨天任务、多步骤任务、周期任务
- 多维度视图：日视图、周视图、月视图、季度视图、年度视图
- 任务分类与等级管理
- 法定节假日显示
- 响应式设计，支持移动端和桌面端

## 2. 技术架构

### 2.1 技术栈选型

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| MonoRepo | TurboRepo | 统一管理多包项目 |
| 运行时 | Bun | 高性能 JavaScript 运行时 |
| 前端框架 | Next.js 14 (App Router) | React 框架，支持 CSR |
| 后端框架 | Hono | 轻量级、边缘计算友好 |
| 通信层 | tRPC | 端到端类型安全 |
| 数据库 | PostgreSQL (Supabase) | 关系型数据库，支持 Supabase Auth |
| ORM | Drizzle ORM | TypeScript 优先，轻量级 |
| 样式 | Tailwind CSS | 原子化 CSS |
| 语言 | TypeScript (strict mode) | 类型安全 |
| 状态管理 | TanStack Query | 服务端状态管理 |
| 拖拽 | dnd-kit | 周视图拖拽功能 |
| 日期处理 | date-fns | 日期计算库 |

### 4.2 数据库 Schema 定义

#### 4.2.1 Todo 表

```typescript
// packages/db/src/schema/todo.ts

import { pgTable, text, timestamp, boolean, integer, uuid, date } from 'drizzle-orm/pg-core';
import { relations } from 'drizzle-orm';
import { createInsertSchema, createSelectSchema } from 'drizzle-zod';

export const todos = pgTable('todo', {
  id: uuid('id').defaultRandom().primaryKey(),
  title: text('title').notNull(),
  description: text('description'),
  
  // 状态
  status: text('status', { enum: ['pending', 'in_progress', 'completed'] }).default('pending').notNull(),
  
  // 时间维度
  startDate: date('start_date', { mode: 'string' }).notNull(),
  dueDate: date('due_date', { mode: 'string' }).notNull(),
  completedAt: timestamp('completed_at'),
  
  // 周期任务
  isCycleTask: boolean('is_cycle_task').default(false).notNull(),
  ruleId: uuid('rule_id'),
  
  // 里程碑标记
  isMilestone: boolean('is_milestone').default(false).notNull(),
  
  // 优先级（已废弃，使用 levelId 替代）
  priority: integer('priority').default(0),
  
  // 关联
  categoryId: uuid('category_id'),
  levelId: uuid('level_id'),
  
  // 任务类型（系统计算字段）
  taskType: text('task_type', { 
    enum: ['basic', 'multi_day', 'multi_step', 'recurring'] 
  }).default('basic').notNull(),
  
  // 时间戳
  createdAt: timestamp('created_at').defaultNow().notNull(),
  updatedAt: timestamp('updated_at').defaultNow().notNull(),
});

export const todosRelations = relations(todos, ({ many, one }) => ({
  subTasks: many(subTasks),
  category: one(taskCategories, {
    fields: [todos.categoryId],
    references: [taskCategories.id],
  }),
  level: one(taskLevels, {
    fields: [todos.levelId],
    references: [taskLevels.id],
  }),
  recurrenceRule: one(recurrenceRules, {
    fields: [todos.ruleId],
    references: [recurrenceRules.id],
  }),
}));
```

## 7. 业务逻辑设计

### 7.1 任务类型判定逻辑

```typescript
// packages/utils/src/task-type.ts

export function determineTaskType(todo: {
  startDate: string;
  dueDate: string;
  subTasks: SubTask[];
  isCycleTask: boolean;
}): TaskType {
  // 周期任务
  if (todo.isCycleTask) {
    return 'recurring';
  }
  
  // 多步骤任务（有子任务）
  if (todo.subTasks && todo.subTasks.length > 0) {
    // 多步骤任务可以是基础任务或跨天任务
    if (todo.startDate !== todo.dueDate) {
      return 'multi_step'; // 跨天多步骤
    }
    return 'multi_step'; // 基础多步骤
  }
  
  // 跨天任务
  if (todo.startDate !== todo.dueDate) {
    return 'multi_day';
  }
  
  // 基础任务
  return 'basic';
}
```

### 7.2 任务完成度计算

```typescript
// packages/utils/src/completion.ts

export function calculateCompletion(subTasks: SubTask[]): number {
  if (!subTasks || subTasks.length === 0) {
    return 0;
  }
  
  const completedCount = subTasks.filter(st => st.isDone).length;
  return Math.round((completedCount / subTasks.length) * 100);
}
```

### 7.4 节假日服务

```typescript
// apps/server/src/services/holiday.service.ts

import { CACHE_TTL } from '../constants';

export class HolidayService {
  private cache: Map<string, HolidayInfo> = new Map();
  
  /**
   * 获取指定月份的节假日信息
   * 优先从缓存获取，否则调用 API
   */
  async getMonthlyHolidays(
    year: number,
    month: number
  ): Promise<Record<string, HolidayInfo>> {
    const cacheKey = `${year}-${month}`;
    
    // 检查缓存
    if (this.cache.has(cacheKey)) {
      return this.cache.get(cacheKey)!;
    }
    
    // 调用 API
    const response = await fetch(
      `https://timor.tech/api/holiday/year/${year}/month/${month}`
    );
    
    const data = await response.json();
    
    // 缓存结果
    this.cache.set(cacheKey, data);
    
    return data;
  }
}

interface HolidayInfo {
  date: string;
  name?: string;
  isHoliday: boolean;
  isWorkday: boolean;
}
```
